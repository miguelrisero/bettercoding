# BetterCoding

> Run Claude Code and Codex in isolated git worktrees, one workspace per task, from a local web UI.

## Quick Start

```bash
npx bettercoding
```

This launches the app locally and opens it in your browser.

Other entrypoints:

```bash
npx bettercoding --help
npx bettercoding --version
npx bettercoding review --help
npx bettercoding mcp --help
```

## Requirements

- Node.js 20.19 or later
- Git
- An authenticated coding agent: [Claude Code](https://docs.anthropic.com/en/docs/claude-code) or [Codex](https://github.com/openai/codex)
