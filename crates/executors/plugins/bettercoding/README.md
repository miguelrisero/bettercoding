# BetterCoding Claude Code plugin

BetterCoding ships this plugin in its binaries and loads it when it starts or
resumes Claude Code. Open a new session or relaunch an existing session to pick
up the bundled version. Invoke it with `/bettercoding:operate`, or ask Claude
Code to use BetterCoding.

The [skill](skills/operate/SKILL.md) also supplies the BetterCoding MCP server's
operating instructions for connected agents. The plugin uses the BetterCoding
MCP connection configured for the session.
